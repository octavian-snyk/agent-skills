# Literal code search

Canonical policy lives in **`LITERAL-CODE-SEARCH.md`** at the repository root.

After skill sync it is also available at the runtime skills root:

- Cursor: **`~/.cursor/skills/LITERAL-CODE-SEARCH.md`**
- Codex: **`~/.codex/skills/LITERAL-CODE-SEARCH.md`**

Resolve the active path:

```bash
python3 ~/.cursor/skills/scripts/agent_config.py --literal-search-policy
```

(Codex: use `~/.codex/skills/scripts/agent_config.py`.)
